# 原型验收清单

- [ ] 首次打开显示空状态，导入入口清晰。
- [ ] 导入 PNG/JPG/WebP/BMP，展示正确的文件名与原图像素尺寸。
- [ ] 画笔涂抹显示半透明蒙版，蒙版不会混入输出图。
- [ ] 橡皮擦仅擦除蒙版；原图保持不变。
- [ ] Ctrl/Cmd+Z、Ctrl/Cmd+Y 可撤销和重做。
- [ ] Telea / Navier–Stokes 可切换；半径和蒙版扩展可调。
- [ ] 修复后显示可拖动的原图/结果分割对比。
- [ ] “继续标记”后可修改蒙版并重新修复。
- [ ] PNG/JPEG 下载文件尺寸与原图一致。
- [ ] 修复失败时恢复按钮状态，临时 OpenCV Mat 被释放。
- [ ] 离线或 API 缺失时显示准确错误，不伪装成已修复。
- [ ] 超过约 12 MP 的图像显示性能提示。
